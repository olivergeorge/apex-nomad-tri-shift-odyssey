# Apex Nomad: Tri-Shift Odyssey

3D open-world sandbox: your off-road motorbike transforms into a jet plane and a deep-sea submarine. Ride desert highways, fly through canyon arches, and explore a lost underwater city.

## ▶ [Play it here](https://olivergeorge.github.io/apex-nomad-tri-shift-odyssey/)

Runs in the browser on desktop and iPad.

## Controls

| Action | Keyboard | Touch |
| --- | --- | --- |
| Move | WASD | Joystick |
| Rocket boost | Shift | Boost button |
| Transform | 1 / 2 / 3 or E | — |
| Jump / ascend | Space | — |
| Pause | Esc | — |

## Run locally

```sh
npm install
npm run dev   # http://localhost:3000
```

## Deploy

Every push to `main` builds and deploys to GitHub Pages via `.github/workflows/deploy.yml`.
